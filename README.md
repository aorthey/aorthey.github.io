# aorthey.github.io

Personal site for [Andreas Orthey](https://aorthey.com), built with [Jekyll](https://jekyllrb.com/).

## Setup

From the repository root:

```bash
bundle install
```

## Run locally (with automatic reloading)

```bash
bundle exec jekyll serve --livereload
```

Then open [http://localhost:4000](http://localhost:4000).

- `--livereload` rebuilds the site when files change and refreshes the browser automatically.
- `jekyll serve` enables file watching by default; LiveReload makes the browser update without a manual refresh.
